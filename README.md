# localhost-hub-v2

Localhost Hub V2 is a Linux-first local development control center built with React, TypeScript, Vite, Tauri v2, and Rust.

The app is intended to combine local project discovery, real service/process management, ports, logs, workspaces, Git workflows, GitHub integration, repo health intelligence, and optional AI-assisted developer tooling.
